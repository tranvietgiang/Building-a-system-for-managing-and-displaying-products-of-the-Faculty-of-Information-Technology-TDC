Hướng dẫn chạy website local

Tài liệu này dùng để chạy dự án trên máy local bằng Vagrant và Docker Compose. Làm theo đúng thứ tự: mở terminal, bật Vagrant, SSH vào máy ảo, build Docker, chạy container, setup database rồi mở website.

0

Yêu cầu trước khi chạy

Máy cần có các công cụ sau:

  • VirtualBox để chạy máy ảo.
  • Vagrant để quản lý máy ảo.
  • Source code dự án nằm trong folder D:\nckh-tdc.
  • Docker và Docker Compose đã được cấu hình trong máy ảo Vagrant.
Nếu chưa cài Vagrant hoặc VirtualBox thì lệnh vagrant up sẽ không chạy được.
1

Mở terminal trong folder dự án

Mở CMD, PowerShell hoặc Terminal tại folder dự án, sau đó chạy:

cd D:\nckh-tdc
2

Bật máy ảo Vagrant

Lệnh này dùng để khởi động máy ảo Ubuntu của dự án:

vagrant up
Nếu máy ảo đã bật sẵn thì có thể bỏ qua bước này và chuyển sang bước SSH.
3

SSH vào máy ảo

Sau khi Vagrant chạy xong, vào máy ảo bằng lệnh:

vagrant ssh
4

Vào folder source trong máy ảo

Sau khi SSH thành công, chạy:

cd /vagrant
Thư mục /vagrant chính là source code được đồng bộ từ máy Windows vào máy ảo.
5

Build Docker Compose

Lần đầu chạy hoặc sau khi sửa Dockerfile/docker-compose thì cần build lại:

docker-compose build

Nếu máy dùng Docker Compose bản mới, dùng lệnh:

docker compose build
6

Chạy các container

Chạy website ở chế độ nền:

docker-compose up -d

Hoặc:

docker compose up -d
7

Kiểm tra container

Kiểm tra các service backend, frontend, mysql, phpMyAdmin có chạy chưa:

docker-compose ps
Nếu trạng thái là Up thì container đã chạy.
8

Setup database Laravel lần đầu

Nếu backend Laravel chưa có file môi trường, tạo file .env và key trước:

docker-compose exec backend cp .env.example .env
docker-compose exec backend php artisan key:generate

Sau đó reset database và thêm dữ liệu mẫu bằng lệnh:

docker-compose exec backend php artisan migrate:fresh --seed --force

Nếu dùng Docker Compose bản mới:

docker compose exec backend cp .env.example .env
docker compose exec backend php artisan key:generate
docker compose exec backend php artisan migrate:fresh --seed --force
Nếu project đã có sẵn file .env thì không cần copy lại từ .env.example.
Lưu ý: lệnh migrate:fresh --seed --force sẽ xóa toàn bộ bảng cũ, tạo lại database mới và thêm dữ liệu mẫu. Chỉ dùng khi muốn reset dữ liệu local.
9

Mở website

Mở trình duyệt và truy cập các đường dẫn sau:

Frontend http://192.168.33.11:5173/dang-nhap
Backend API http://192.168.33.11:8000
phpMyAdmin http://192.168.33.11:8080
Nếu phpMyAdmin không mở được, kiểm tra lại port trong file docker-compose.yml.
10

Chạy lại website lần sau

Nếu Docker đã build rồi, lần sau chỉ cần chạy:

cd D:\nckh-tdc
vagrant up
vagrant ssh
cd /vagrant
docker-compose start

Hoặc nếu muốn chắc chắn container chạy lại đầy đủ:

cd D:\nckh-tdc
vagrant up
vagrant ssh
cd /vagrant
docker-compose up -d
11

Dừng website

Khi muốn dừng các container nhưng vẫn giữ máy ảo:

docker-compose stop

Khi muốn thoát SSH và tắt luôn máy ảo Vagrant:

exit
vagrant halt
?

Lệnh kiểm tra và xử lý lỗi nhanh

Xem log toàn bộ container

docker-compose logs -f

Xem log backend

docker-compose logs -f backend

Restart toàn bộ container

docker-compose restart

Xóa cache Laravel

docker-compose exec backend php artisan optimize:clear
Nếu website không vào được, hãy kiểm tra theo thứ tự: Vagrant đã bật chưa → container có trạng thái Up chưa → đúng IP/port chưa → backend có lỗi log không.
!

Lỗi thường gặp

  • Không vào được website: kiểm tra lại link http://192.168.33.11:5173/dang-nhap.
  • Frontend gọi API lỗi: kiểm tra backend có chạy ở port 8000 không.
  • Database lỗi: chạy lại php artisan migrate:fresh --seed --force nếu muốn reset dữ liệu local.
  • Sửa code nhưng chưa thấy thay đổi: restart container hoặc clear cache Laravel.
  • Docker Compose không nhận lệnh: thử đổi giữa docker-compose và docker compose.
